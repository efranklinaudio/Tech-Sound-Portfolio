# Tech-Sound-Portfolio
Hello! This is a repository containing the files of some of my solo audio redesign projects
These projects are: A full audio redesign of the Sample Project: Lyra, with a focus on weapon sfx and mixing in a TPS. An audio redesign on the first section of Quixel Megascan's Medieval Village, with a focus mainly on Ambience. And a single script movement system using the base Third Person Character Project
